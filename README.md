# To-Do List

A simple and interactive task management web application built using **React** and **Vite**. The application allows users to organize their daily tasks through a clean and user-friendly interface.

## Features

- **Add Tasks:** Create new tasks with input validation to prevent empty entries.
- **Delete Tasks:** Remove completed or unwanted tasks.
- **Reorder Tasks:** Move tasks up or down to organize priorities.
- **Interactive Interface:** Manage tasks dynamically using React state.

> **Note:** Tasks are stored in memory and reset when the page is refreshed.

## Technologies Used

- **React** – Building reusable UI components
- **JavaScript (JSX)** – Application logic and event handling
- **CSS** – Styling and layout
- **Vite** – Frontend development tooling

## Getting Started

**Prerequisites:** Node.js and npm.

1. Clone the repository:

   `git clone https://github.com/Alaa-ms-eng/To-Do-List.git`

2. Navigate to the project directory:

   `cd To-Do-List`

3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`

Open the local URL displayed in your terminal.

## Project Structure

- `src/App.jsx` – Main application component
- `src/ToDoList.jsx` – Task management logic and UI
- `src/index.css` – Application styling
- `src/main.jsx` – React application entry point
